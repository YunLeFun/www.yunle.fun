## 欢迎来到云乐坊

我们很高兴地宣布，云乐坊官网正式上线！

## 云乐坊是什么

云乐坊是一个 Web 应用平台，目前初版包含以下功能：

### 账号系统

云乐坊已上线统一的账号系统。用户注册后，可以在平台下的多个 Web App 中同步自己的数据，无需重复注册。

### 应用中心

用户可以在应用中心浏览和访问云乐坊提供的各种 Web 应用。

### 文档中心

提供详细的使用文档和开发指南，帮助用户快速上手。

## 技术栈

云乐坊官网采用以下技术构建：

- **Nuxt 3** - Vue.js 全栈框架
- **Nuxt UI** - UI 组件库
- **CloudBase** - 腾讯云开发，提供静态网站托管服务

## 展望未来

这仅仅是云乐坊的开始。我们将继续完善功能，欢迎体验！
