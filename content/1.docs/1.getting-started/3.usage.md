## 普通用户指南

### 注册与登录

1. 访问[注册页面](/signup)创建账号，或通过 GitHub 账号快速登录。
2. 登录后可在[个人设置](/settings)中完善你的资料。

### 浏览与使用应用

1. 前往[应用市场](/apps)，浏览或搜索你感兴趣的应用。
2. 点击应用卡片进入详情页，了解应用功能和说明。
3. 访问[下载页面](/apps/download)获取跨平台客户端。

### 订阅会员

1. 前往[会员页面](/pricing)，选择适合你的方案。
2. 完成支付后，会员特权立即生效。
3. 你可以随时在[个人设置](/settings)中管理订阅。

## 开发者指南

### 创建应用

1. 登录后前往[创建应用](/apps/new)页面。
2. 填写应用名称、标识符、描述等基本信息。
3. 可选关联 GitHub 仓库，便于代码管理。
4. 设置应用为公开或私有，提交即可创建。

### 管理应用

- 在[应用市场](/apps)中查看你创建的所有应用。
- 点击应用进入详情页，可进行编辑或删除操作。
- 应用标识符（slug）创建后不可修改，请谨慎设置。

### 开发者工具

前往[开发者平台](/developer)了解完整的开发工具链：

- **云端 IDE**：在线编写和调试代码。
- **API 管理**：支持 RESTful 和 GraphQL 接口。
- **自动部署**：关联 GitHub 仓库后，推送代码自动触发 CI/CD 流水线。
- **SDK & 组件库**：快速集成常用功能模块。
