## 浏览与使用应用

1. 前往[云端应用图谱](/explore)，浏览或搜索你感兴趣的应用。
2. 选择应用，阅读功能、入口和使用说明。
3. 大多数基础功能可以直接体验；需要账号能力时，应用会引导你登录。

## 创建与使用账号

1. 访问[注册页面](/signup)创建账号，或在登录页选择支持的第三方账号登录。
2. 登录后前往[个人设置](/settings)，完善资料并管理登录方式。
3. 同一账号可用于支持云乐坊统一登录的应用；授权前，页面会明确展示目标应用和所需权限。

## 管理会员与云币

- 前往[会员页面](/pricing)查看当前会员权益与价格。
- 前往[云币钱包](/wallet)查看余额、充值记录和消费明细。
- 会员与云币是两类独立权益：会员按有效期生效，云币用于支持按次消费的功能。

## 开发者接入

云乐坊目前优先打磨和上架官方应用，第三方开发者自助发布与开发者套餐尚未开放。

应用接入、统一账号、支付和 SSO 的公开说明集中在[云乐坊开发者文档](https://docs.yunle.fun)，官网文档不再重复维护技术细节。

## 获取帮助

技术问题可以通过 GitHub Issues 反馈；账号、订单、退款和支付凭证等私密问题，请查看[联系我们](/docs/contact)并使用私密客服渠道。
