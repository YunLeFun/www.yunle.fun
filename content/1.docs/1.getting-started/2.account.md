## 如何创建账号

云乐坊目前支持以下账号方式：

| 方式 | 新用户创建账号 | 已有账号登录 |
| --- | --- | --- |
| 中国大陆手机号验证码 | 支持，首次验证后自动创建 | 支持 |
| GitHub | 支持，首次授权后自动创建 | 支持 |
| 邮箱验证码 | 暂不支持 | 支持已绑定邮箱 |
| 用户名、手机号或邮箱 + 密码 | 不创建账号 | 支持已设置密码的账号 |

新用户可以前往[登录 / 注册页面](/login)，使用中国大陆手机号或 GitHub 继续。首次验证或授权成功后，系统会自动创建云乐坊账号。继续操作即表示你同意云乐坊的[服务条款](/docs/terms-of-service)和[隐私政策](/docs/privacy-policy)。

## 为什么暂不支持邮箱直接注册

邮箱地址和一次性邮箱获取成本较低，直接开放邮箱注册容易被用于批量创建账号、滥用平台资源或发布垃圾内容。为保护正常用户的账号和平台体验，云乐坊现阶段暂不开放邮箱直接注册。

这不影响邮箱作为登录方式使用。完成账号创建并绑定邮箱后，你仍然可以使用邮箱验证码登录；如已在账号安全设置中创建密码，也可以使用邮箱和密码登录。

我们会在验证码发送具备更完善的人机校验、限频和异常注册监控后，重新评估是否开放邮箱注册。

## 如何绑定邮箱

1. 先使用中国大陆手机号或 GitHub [登录或创建账号](/login)。
2. 登录后进入[个人设置](/settings)。
3. 在账号安全设置中填写邮箱并完成验证码验证。
4. 绑定成功后，即可在登录页使用该邮箱接收验证码登录。

绑定邮箱不会创建新账号，也不会改变当前账号。一个邮箱如果已经绑定其他云乐坊账号，不能再次绑定；请改用其他邮箱，或退出后登录原账号。

## 常见问题

### 输入邮箱后无法获取验证码，是系统故障吗？

不一定。邮箱验证码只发送给已经绑定该邮箱的账号。如果这是你第一次使用云乐坊，请先通过手机号或 GitHub 创建账号，再到个人设置中绑定邮箱。

为避免泄露某个邮箱是否已经注册，公开登录页面不会直接确认邮箱是否存在。请先检查邮箱拼写是否正确；如果确认已经绑定但仍无法获取验证码，可以前往[支持中心](https://support.yunle.fun/login-help)寻求帮助。

### 可以只使用邮箱，不绑定手机号吗？

可以。你可以通过 GitHub 创建账号，再绑定邮箱。绑定完成后，可以使用邮箱验证码登录，无需额外绑定手机号。

### 绑定邮箱会合并两个账号吗？

不会。邮箱只能绑定到一个账号，绑定操作不会自动创建、合并或迁移其他账号的数据。如果邮箱已被其他账号使用，请登录原账号或联系支持中心处理。
