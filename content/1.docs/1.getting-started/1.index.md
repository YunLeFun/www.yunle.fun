**云乐坊**（yunle.fun）是一个云端应用集合。我们希望把实用、好玩或有一点奇思妙想的作品放在同一个入口，让你不必安装复杂的软件，也能随时打开使用。

目前平台优先打磨和上架官方应用，第三方开发者自助发布与开发者套餐尚未开放。

## 你可以在这里做什么

- **发现应用**：前往[云端应用图谱](/explore)，按分类或关键词寻找感兴趣的应用。
- **直接体验**：大多数基础功能无需登录；需要保存数据或使用平台权益时，再按提示登录。
- **使用统一账号**：一个云乐坊账号可用于支持统一登录的云乐坊应用，并管理个人资料、安全设置、会员与云币。
- **管理平台权益**：云乐坊会员目前为 ¥10/月或 ¥100/年，完整权益与购买说明见[会员页面](/pricing)。
- **了解更新**：通过[博客](/blog)和[更新日志](/changelog)查看新应用与功能变化。

## 推荐使用路径

1. 打开[云端应用图谱](/explore)，先看看现在有哪些应用。
2. 进入感兴趣的应用，阅读说明后直接开始体验。
3. 需要保存状态、使用会员或云币权益时，[创建账号](/signup)或登录。
4. 在[个人设置](/settings)中管理资料、登录方式与安全选项。

## 文档应该去哪里找

官网文档面向使用云乐坊的普通用户，提供入门、账号帮助、联系方式和法律说明。

如果你关注应用接入、统一账号、支付或 SSO，请前往[云乐坊开发者文档](https://docs.yunle.fun)。第三方应用的自助发布尚未开放，公开文档用于说明现有接入边界和后续开放规范。

## 遇到问题

使用中遇到故障、支付或退款问题，或者需要提交客诉，请查看[联系我们](/docs/contact)。

请勿在公开的 GitHub Issues 中提交账号、订单号、支付凭证等隐私信息；这类问题请使用客服邮箱或微信客服渠道。
