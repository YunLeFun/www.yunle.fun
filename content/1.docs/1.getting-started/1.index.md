**云乐坊**（yunle.fun）是一个云端应用平台，集应用市场、开发者工具与社区于一体。用户可以在这里探索、使用各类有趣的云端应用，开发者可以创建并发布自己的作品。

## 站点功能

云乐坊包含以下核心模块：

- **应用市场**：浏览、搜索和使用社区中的云端应用，支持跨平台下载。
- **开发者平台**：提供云端 IDE、API 管理、自动部署（CI/CD）、全球 CDN 加速等工具链，帮助开发者快速构建和发布应用。
- **文档中心**：包括入门指南、基础知识和开发者文档，帮助你快速上手。
- **博客 & 更新日志**：了解平台最新动态、功能更新和技术文章。
- **会员体系**：提供多级会员方案，解锁更多存储空间和高级功能。

## 用户角色

平台面向两类用户，提供差异化的功能和体验：

### 普通用户（使用者）

面向希望探索和使用云端应用的大众用户：

- 浏览和搜索应用市场中的应用
- 下载和使用已发布的云端应用
- 云同步个人数据和偏好设置
- 订阅会员以获得更多存储空间和高级特权
- 通过客服渠道反馈问题和建议

### 开发者

面向希望创建和发布应用的技术用户：

- 创建、编辑和管理自己的应用
- 关联 GitHub 仓库，实现代码托管和版本管理
- 使用云端 IDE、自动部署、弹性扩展等开发者工具
- 接入 SDK & 组件库，快速构建应用
- 在应用市场上架作品，与社区分享
- 开发者独立定价方案（免费版 / 专业版 / 企业版），详见[开发者平台](/developer)
