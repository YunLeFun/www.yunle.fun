配置完成后，你可以在 CodeBuddy 的 AI 对话中直接用自然语言操作 CloudBase 服务，无需切换到云控制台。

::callout{icon="i-ri:magic-line" color="primary"}
**使用示例：** "创建用户表" → AI 自动创建数据库集合 · "部署这个函数" → AI 自动上传并配置云函数 · "部署前端到 CDN" → AI 自动上传文件并配置托管
::

## 前置条件

### Node.js 环境

确保已安装 **Node.js v18.15.0 或更高版本**：

```bash
node --version
```

如未安装，请从 [Node.js 官网](https://nodejs.org/en/download){target="\_blank"} 下载。

### 云开发环境

参考 [开通云开发环境](https://docs.cloudbase.net/quick-start/create-env){target="\_blank"}，新用户可免费开通体验。

## CodeBuddy IDE 版（推荐）

CodeBuddy IDE 版用户无需手动配置 MCP：

::steps

### 打开设置

进入 **设置页 → 集成**。

### 授权 CloudBase

点击 **"Tencent CloudBase"** 管理按钮并完成授权。

### 开始使用

在 AI 对话中直接用自然语言操作 CloudBase 服务。
::

## CodeBuddy 插件版

### 方式一：MCP 市场安装（推荐）

1. 点击 CodeBuddy **右上角的 MCP 按钮**
2. 在 MCP 市场中搜索 **CloudBase**
3. 点击 **安装** 即可

### 方式二：手动配置 MCP

在 MCP 配置文件中添加：

```json
{
  "mcpServers": {
    "cloudbase": {
      "command": "npx",
      "args": ["@cloudbase/cloudbase-mcp@latest"],
      "env": {
        "INTEGRATION_IDE": "CodeBuddyManual"
      }
    }
  }
}
```

配置完成后，在 AI 对话中输入以下内容安装 Skills：

```
安装 CloudBase Skills：命令 npx skills add tencentcloudbase/cloudbase-skills -y
```

## 常见问题

::field{name="MCP 连接失败？" type="解决方案"}
检查配置文件格式是否正确，重启 CodeBuddy，确认网络连接正常。
::

::field{name="工具数量显示为 0？" type="解决方案"}
参考 [常见问题文档](https://docs.cloudbase.net/ai/cloudbase-ai-toolkit/faq){target="\_blank"} 中的相关说明。
::
