## 特别提示

海州区云乐坊信息技术工作室（以下简称“我们”或“云乐坊”）是本产品的个人信息处理者。我们重视您的隐私和个人信息安全，本政策说明您使用云乐坊网站、iOS App 及相关服务时，我们如何收集、使用、存储、共享和保护个人信息，以及您如何行使相关权利。

请在使用服务前仔细阅读本政策。对于依法需要取得同意的处理活动，我们会通过功能页面、系统权限弹窗等方式向您说明并取得同意；您可以拒绝非必要权限或撤回同意。拒绝或撤回不会影响此前基于同意进行的处理，但相应功能可能无法继续使用。

## 一、我们如何收集和使用个人信息

我们遵循合法、正当、必要和诚信原则，仅为下列目的处理与功能相匹配的信息：

您发布的工坊应用、评论等内容可能对其他用户公开。请勿在公开内容中填写不必要的个人信息。搜索关键词等仅在实现相应功能、排障或安全控制所需时处理。

## 二、Cookie、本地存储和同类技术

网站及 App 内的 WebView 会使用 Cookie、localStorage 和同类技术，以维持登录、保存您的设置并完成监控。主要类别如下：

1. **认证与会话**：`ylf_access_token`、用户资料镜像、CloudBase refresh token 和会话数据。相关 Cookie 的最长有效期通常为 31 天，退出登录、注销或会话失效时会相应清理或失效。
2. **登录便利**：已保存账号、上次手机号、上次密码登录账号等。我们不会在这些项目中保存明文密码；完整手机号使用的 Base64 只是可逆混淆，不是加密。
3. **功能与偏好**：主屏和 Dock 配置、最近使用、目录缓存、工坊草稿、购买记录、主题模式及云同步设置。
4. **运行监控**：腾讯云 RUM Aegis 在 localStorage 生成并保存随机 `aid`，用于区分访问用户和计算 UV。

您可以通过退出登录、应用内设置、浏览器设置、清除网站数据或卸载 App 管理这些信息。清除必要的会话或功能数据后，您可能需要重新登录或重新配置功能。

## 三、受托处理、共享、转让和公开披露

为提供具体功能，我们会委托下列服务提供方处理必要信息，或按照您主动选择的功能与其共享：

| 服务提供方                                     | 涉及的功能和信息                                                            | 处理目的                                         |
| ---------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------ |
| 腾讯云 CloudBase                               | 账号和会话、CloudBase UID、云居同步、工坊/社区内容、AI 会话、交易核验结果等 | 身份认证、数据库、云函数、文件存储和业务服务     |
| 腾讯云 RUM（Aegis）                            | 页面访问、`aid`、登录后的 CloudBase UID、错误、接口/资源测速和性能指标      | 错误监控、访问统计和性能分析                     |
| 腾讯云 CloudBase AI Bot 及功能中配置的模型服务 | AI 提示词、上下文、工具调用信息和回复                                       | 生成 AI 回复并完成用户请求                       |
| 腾讯云文本内容安全 TMS                         | 评论、举报等等待审核的文本                                                  | 识别违法违规或不适宜内容，辅助自动审核和人工复核 |
| 微信 OpenSDK                                   | 微信授权结果、OpenID、UnionID                                               | 在您选择时完成微信登录和账号绑定                 |
| Apple StoreKit、App Store Server API           | 商品 ID、交易 ID、购买/恢复结果                                             | 完成 App 内购买、恢复权益和验证交易              |

上述服务提供方会依其适用的隐私规则和我们与其约定的目的处理信息。除上述情形外，我们不会出售个人信息，也不会为跨公司定向广告共享个人信息。

您通过云乐坊打开第三方云应用或网站后，对方可能按照其自身规则使用 Cookie、网络请求或收集信息。该第三方是独立的服务提供者，请在使用前阅读其隐私政策和服务条款。云乐坊不会向第三方云应用注入您的 CloudBase access token 或 refresh token。

发生合并、分立、收购、资产转让或破产清算等变更时，如涉及个人信息转让，我们会依法告知接收方信息，并要求其继续受本政策约束；处理目的或方式发生变化的，将依法重新取得您的同意。

我们仅会在取得您的单独同意，或法律法规、司法或行政机关依法要求的情况下公开披露个人信息。

## 四、存储地点和期限

1. **存储地点**：账号、认证及主要业务数据通过腾讯云 CloudBase 存储于上海；运行监控数据通过腾讯云 RUM 存储于广州，均位于中华人民共和国境内。Apple 的购买交易由 Apple 按其服务规则处理。
2. **账号与会话**：账号资料和账号绑定信息在账号存续期间保留；会话按有效期或退出状态失效。申请注销后进入 30 天冷静期，冷静期届满且清理完成后删除或匿名化依法无需继续保留的信息。
3. **功能配置与用户内容**：本地配置保留至您主动清除网站数据、重置或卸载 App；云端同步配置保留至您删除、覆盖或注销账号。工坊、评论、举报和审核数据在内容展示、审核、申诉及安全处置所需期间保留，之后删除或匿名化；涉及未决举报、争议或违法违规处置的记录会保留至相关事项处理完成。
4. **AI 数据**：会话内容在提供对话、历史记录和安全审查所需期间保留；您删除会话或注销账号后，我们将删除或匿名化依法无需保留的内容。
5. **交易数据**：商品、交易、会员及云币流水在履约、对账、退款、审计和争议处理所需期间，以及法律法规要求的期限内保留；这类记录不会因账号注销而同步立即删除，但会受到访问控制并在期限届满后删除或匿名化。
6. **运行监控**：腾讯云 RUM 上报的错误、自定义上报和页面访问等原始日志保留 30 天；期限届满后按服务规则删除或汇总。设备上的 `aid` 保留至您清除对应本地存储或卸载 App。

如依法需要延长保存期限，我们仅在法律要求的范围内保存并采取访问限制。超过必要期限后，我们会删除或匿名化相关信息。

## 五、我们如何保护个人信息

我们采取 HTTPS 加密传输、访问控制、权限隔离、安全审计和备份等措施，努力防止信息被未经授权访问、使用、修改、披露、损坏或丢失。只有为履行职责确有必要的人员和系统才能访问相关信息。

互联网环境无法保证绝对安全。如发生可能危害您权益的个人信息安全事件，我们将依法采取补救措施，并通过站内通知、邮件、公告等方式告知事件情况和建议措施；难以逐一告知时，我们会以合理有效的方式发布公告。

## 六、您的权利

您依法享有查询、复制、更正、补充、删除个人信息，撤回同意，以及注销账号等权利：

1. 您可在相关功能页面查看、修改账号资料，管理本地配置和用户内容。
2. 您可通过系统设置撤回相机、相册等权限，或通过退出登录、清除本地数据管理会话和偏好。
3. 您可在应用内“设置 → 账号 → 注销”申请注销。提交后进入 30 天冷静期，会员、云币、支付、AI、存储和第三方授权等业务能力会冻结；您可在截止时间前通过账号状态页明确恢复账号。冷静期届满后注销不可恢复，我们会按本政策第四部分处理相关数据。
4. 如功能页面无法完成您的请求，可发送邮件至 `i@yunle.fun`，申请访问、复制、更正、删除、注销或进行投诉举报。

为保障账号和信息安全，我们可能先核验您的身份。一般情况下，我们将在十五个工作日内答复；复杂情形下会依法说明所需时间。合理请求原则上不收费，但对重复、超出合理限度或明显不具备依据的请求，我们可能依法拒绝并说明理由。

## 七、未成年人保护

我们的产品主要面向成年人，不以不满 14 周岁的儿童为目标用户。未经父母或其他监护人同意，儿童不应自行创建账号或提供个人信息。若我们发现未经可验证的监护人同意收集了儿童个人信息，将尽快删除或采取法律要求的其他措施。监护人如有疑问，可通过 `i@yunle.fun` 联系我们。

## 八、跨境提供

原则上，我们在中华人民共和国境内收集和产生的个人信息存储于境内。如因您主动使用 Apple 等第三方服务或业务需要确需向境外提供个人信息，我们将依照适用法律完成安全评估、个人信息保护认证或标准合同等要求，并在需要时另行告知接收方、处理目的、信息种类和权利行使方式，取得您的单独同意。

## 九、政策更新

我们可能根据功能、处理活动或法律要求更新本政策。对于处理目的、信息种类、共享对象或权利行使方式等重大变化，我们会通过页面提示、站内通知或其他显著方式告知，并在依法需要时重新取得您的同意。更新后的政策会在本页面标明最近更新日期和生效日期。
